Visualising Future Climate Projections with Open-Source Python (From CMIP6 Data to Interactive Web Maps)
https://talks.osgeo.org/foss4g-2026-workshop/talk/3DECQE/



**About**

Accessing and visualising climate data can be challenging due to high volume of available datasets and the significant memory requirements that come with processing them. This workshop guides participants accessing CMIP6 climate model data, processing it with Python, computing different climatic indicators and develop interactive web maps using MapLibre GL.



**What are the takeaways for the participants?**

* Accessing CMIP6 climate data from Google Cloud via the Pangeo intake catalog
* Working with NetCDF/Zarr using xarray, regional subsetting
* Computing climate indicators (heat threshold days, rainfall anomalies)
* Publication-quality static maps with Cartopy/Matplotlib
* Building an interactive web map with MapLibre GL



**Prerequisites**

* A laptop with a browser (everything runs in Colab & no local install required)
* Basic Python / Jupyter familiarity
* No climate science background needed
